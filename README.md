# HelpR - помощник HRам
По своей сути является приложением-опросником. На вопросы должен отвечать HR после собеседования с потенциальным кадром. В результате на основе ответов выдается ответ о том подходит ли этот человек компании или нет.

В качестве фреймворка использовались WinForms.

*P.S. Очень много плохого кода, но дизайн вроде ниче такой*
